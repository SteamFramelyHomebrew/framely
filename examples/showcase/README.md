# SDK showcase

[简体中文](README.zh-CN.md)

Demonstrates a React quick page, persistent data, separate windows, and notifications. It is a plugin development reference and is not automatically enabled when Framely is installed.

Run `npm ci && npm run build` at the repository root to generate `payload/page.js` and `payload/backend.py`, then package and install as described in the [plugin development reference](../../docs/plugin-development.md). `payload/icon.png` is the example's source icon.
